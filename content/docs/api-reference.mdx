## `createClient(options)`

Creates a client. Call it once per process and share the instance — each client
maintains its own cache and sync connection.

```ts
import { createClient } from '@nimbus/client';

const nimbus = createClient({ projectKey: 'pk_...', region: 'eu-central' });
```

Returns a `NimbusClient`. See [Configuration](/docs/configuration) for the full
options table.

## `ChangeEvent<T>`

```ts
type ChangeEvent<T> =
  | { type: 'changed'; origin: 'local' | 'remote'; record: T }
  | { type: 'deleted'; origin: 'local' | 'remote'; id: string }
  | { type: 'conflict'; local: T; remote: T; resolved: T };
```

## Error codes

| Code | HTTP | Retryable | Meaning |
| --- | --- | --- | --- |
| `NIMBUS_UNAUTHORIZED` | 401 | No | Key missing, malformed, or revoked |
| `NIMBUS_FORBIDDEN` | 403 | No | Key lacks the required scope |
| `NIMBUS_NOT_FOUND` | 404 | No | Collection does not exist |
| `NIMBUS_CONFLICT` | 409 | No | Resolver rejected the write |
| `NIMBUS_RATE_LIMITED` | 429 | Yes | Honour the `Retry-After` header |
| `NIMBUS_QUEUE_OVERFLOW` | — | No | Local queue exceeded its cap |
| `NIMBUS_UNAVAILABLE` | 503 | Yes | Region degraded; the SDK retries |

```ts title="Handling errors"
import { NimbusError } from '@nimbus/client';

try {
  await notes.put(record);
} catch (error) {
  if (error instanceof NimbusError && error.retryable) {
    // The SDK already retried; surface a transient banner.
    return showBanner('Reconnecting…');
  }
  throw error;
}
```
